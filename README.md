
# Excel Data Cleaning and Validation Project

## Overview
This project demonstrates data cleaning and validation techniques using Microsoft Excel to prepare a transactional dataset for accurate analysis.

The dataset was initially raw and inconsistent. Through this project, it was transformed into a structured, reliable, and analysis-ready dataset, highlighting real-world data quality practices.

---

## Project Steps

1.Structured Dataset
   - Created a working copy of the dataset and formatted it into an Excel Table for easier manipulation.

2.Duplicate Removal
   - Identified and removed duplicates using unique transaction IDs.

3.Missing Value
   - Filled missing entries for key fields like item name, quantity, and location with appropriate replacements.

4.Invalid Value Correction
   - Detected invalid values (e.g., "Unknown" or errors) and replaced them with proper entries.

5.Date Standardization
   - Converted dates into a consistent **MM/DD/YYYY** format.
   - Organized transactions chronologically from January to December.

6.Feature Enhancement
   - Added a new column **Transaction Month** to enable trend analysis.
